## Design Context

### Users
The product is for the owner/operator of the IMPO command center who manages
tmux-backed coding agents across several machines. On mobile the user acts
quickly with one hand; on Web the same user scans more sessions at once and
opens a focused terminal or artifact without losing fleet context.

### Brand Personality
Quiet, utilitarian, precise. The interface should feel like a dependable
control surface for work already in progress, not a marketing product or
showcase.

### Aesthetic Direction
ChatGPT-inspired calm workspace: a soft navigation rail, a clean reading canvas,
quiet neutral surfaces, round direct controls, and typography-led hierarchy.
Web should preserve the mobile information architecture while using desktop
space appropriately: session-grouped cards stay expanded on desktop and tablet;
phone-sized Web layouts mirror the iOS behavior by starting collapsed and
allowing only one card to be open at a time.

### Design Principles
- Organize the fleet by machine, tmux session, then window so related work reads
  as one unit across clients.
- Preserve information density and glanceability; recent, active, and waiting
  state must remain easy to scan.
- Keep desktop and tablet cards expanded and use grouping/layout—not progressive
  disclosure—to manage their density. On phones, default every card to collapsed
  and expand at most one card at a time.
- Make terminal output, the current working directory, its files, and generated
  artifacts feel like one continuous workflow.
- Prefer familiar, direct controls and keep state trustworthy across refreshes,
  reconnects, and device sizes.
- Avoid card-on-card framing, decorative gradients, animated borders, and heavy
  shadows. Use pale hover fills, whitespace, and a small number of dark anchors.

## Approved visual direction — 2026-09-27

Use sibling Instant’s approved B “paper and light glass” style across Web, iOS and Android: warm ivory paper, forest ink, sage selection, warm orange accents, Georgia/serif display titles and thin paper borders. Dark mode uses deep forest surfaces and warm ivory text. Keep glass restrained to controls; preserve the command center hierarchy, responsive folding and existing interactions. T-MAX has its own original folded-paper multiplex mark, not the Instant logo.

## Session Drafts — 2026-10-18

The owner reviews complete Agent deliverables in one stable HTML page, selects
text and comments, then asks the same session to revise it. Keep the document
central, with a quiet library rail and a separate feedback column. Preserve
typed comments across refreshes and show the version attached to every quote.
Use the approved Instant paper palette in light and dark themes.

## Solarized Web preview — 2026-10-19

The owner requested a live Solarized preview. Web now uses the official palette:
light ivory/base3 and dark blue-teal/base03, slate text, blue focus and yellow
primary terminal actions. Preserve the existing layout, typography and
Auto/Light/Dark behavior. The owner subsequently requested matching native
iOS/Android colors; production OTA now carries the same palette for runtime 7
and the runtime 6 Android backport.

## Dark-mode reading contrast — 2026-10-27

The owner requested brighter dark-mode text, using ChatGPT's near-white text as the readability reference. Keep the Solarized backgrounds and all light-mode colors. Dark primary text and neutral actions use #eee8d5; secondary text uses #c0cdcd. Apply the same colors to Web, native and terminal viewers. Do not fade inactive native cards below 0.86 opacity in dark mode.

## Vision Pro input priority — 2026-10-31

The owner frequently operates this app on Vision Pro and cannot reliably type.
Voice and direct button selection are primary inputs there. Keep Start, Stop,
Send, Clear and service selection reachable without a keyboard, hover or long
press. Show microphone state and the actual speech service clearly. Preserve
the current restrained theme and provide large, separated hit targets. Do not
claim real Vision Pro comfort or microphone validation from browser simulation.
